# Point – Web

Sitio estático (HTML + CSS + JS). Abre `index.html` o súbelo a GitHub Pages.

```
index.html  app.html  estadisticas.html  comunidad.html  raqueta.html
token.html  progresa.html  planes.html  preguntas.html
css/styles.css   js/main.js  js/raqueta.js  js/auth.js
assets/img/      (logos de Point, marcas y fotos de palas en palas/)
```

- Las imágenes de `assets/img/brands/` son **de relleno**: reemplázalas por los logos oficiales / foto real (mismo nombre de archivo).
- El formulario de `progresa.html` valida en el navegador; falta conectarlo a un backend.

**GitHub Pages:** sube la carpeta a un repo → Settings → Pages → Branch `main` / root.
